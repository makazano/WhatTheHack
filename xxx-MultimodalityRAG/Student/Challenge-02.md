## Introduction

In this challenge, you will focus on processing the data ingested from magazine images and sales data. You will learn how to prepare this data for retrieval and querying in the multimodal Retrieval-Augmented Generation (RAG) pipeline.

## Description

In this challenge, you are asked to:
- **Examine Data**: There are magazine images in the [images](./Resources/data/images) folder, and a csv table in the [data](./Resources/data/) folder that includes sales data about the magazines. Review the data and determine if any normalization or cleaning is required before ingestion.  
- **Explore AI Services**: Explore the speech-to-text API to understand how it can be used to implement the target architecture   
- **Ingest Data**: Load the magazine images to Azure Data Lake Storage gen2 and the sales data to SQL. 

## Success Criteria

To complete this challenge successfully, you should be able to:

- Verify that the magazine images and sales data have been reviewed and any necessary normalization or cleaning has been performed.
- Demonstrate the use of the speech-to-text API and explain its potential applications in this context.
- Show that the magazine images have been successfully loaded into Azure Data Lake Storage gen2.
- Show that the sales data has been successfully loaded into SQL.
