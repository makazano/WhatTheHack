## Introduction

Thank you for participating in the MultimodalityRAG What The Hack. Before you can hack, you will need to set up some prerequisites.

## Common Prerequisites

To get started, please ensure that your Azure Subscription is valid. Then, create a resource group named "MultimodalityRAG". This resoruce group will house all of the required resoruces for this hack. You will then need all of the following resources:
*  Azure OpenAI
*  Blob Storage Account
*  Azure AI Vision
*  Azure Search Service
*  Azure Machine Learning Service

## Success Criteria

To complete this challenge successfully, you should be able to:

- Create all of the above resoruces.
- Set up an Azure Machine Learning Notebook and compute Instance
